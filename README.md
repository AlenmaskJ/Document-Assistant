# Document-Assistant
## 现状痛点：
#### 1.若个人电脑大量文档，会有检索困难，无法快速定位问题。需要单独打开每个文档去查看核心内容、大意、关键词等，从中才能找出自己所需文档
#### 2.若公司有文档AI检索工具，海量的文档库检索存在着模糊匹配问题，无法找出有效符合自己需求文档，或是大量相关文档检索结果

## 程序优缺点：
### 优点：
#### 1.用于在大量文档中，人机结合实现快速检索出个人所需文档
#### 2.根据自己积累的文档，开发独属于自己的文档知识库，成为最懂你的文档检索智能体
#### 3.无需联网启动程序，文档安全性、隐私性有保证
### 缺点：
#### 1.需按照文档格式要求整理好自己的文档库，便于提高检索效率
### 对比其他产品：
#### 1.例如everything工具的功能，该程序实现对文档核心内容、文档大意、核心关键词的匹配
